# Progress Log

Append entries here as phases and tasks complete.
Never delete entries. This is the institutional memory of the build.

---

## How to Use This File

Start every LLM session with:
```
Before we start, read:
1. .llm/PROGRESS.md — understand what's been built and any decisions made
2. .llm/PLAN.md — find the next unchecked task in the current phase
3. .llm/CONVENTIONS.md — follow these rules for all code
```

| | `PLAN.md` | `PROGRESS.md` |
|---|---|---|
| **Purpose** | Where are we going | Where have we been |
| **Updated** | When tasks start/complete | When sessions end |
| **Content** | Ordered task list | Decisions, gotchas, completed work |
| **Grows over time** | Gets shorter (tasks check off) | Gets longer (append only) |
